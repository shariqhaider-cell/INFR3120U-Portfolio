# This is my Portfolio Website

## Description
    This is my portfolio website which showcases the projects and work I have completed during my studies.

    It also includes information about me, my projects, and how to contact me.

## Responsive Design

    The website uses separate CSS files for mobile, tablet and laptop screen sizes.

    Media queries help the website adjust to different screen sizes and devices:

    - Mobile: Up to 600px.
    - Tablet: From 601px to 1024px.
    - Laptop: 1025px and above.

    These screen sizes help the website adjust to different device sizes, making the content easier to see and read on phones, tablets and laptops.

## Gradient

    I used a linear gradient for the website's background. It uses a 135-degree angle with dark blue colours to create an angled gradient.

    I also used a linear gradient for the main heading on each page, transitioning between dark blue and lighter blue colours to make the heading more appealing.

## Colour Scheme
    I used an analogous colour scheme from Adobe Color. I used dark blue and light blue colours for the background, headings, navigation, and footer.

    I used the same colour scheme throughout the website to keep all four pages consistent. Darker blue colours are used for the main background, while blue colours are used for the navigation background.
    
    Light blue is used for the main heading gradient and footer background. I used white for the text on the main background and black for the text in the footers.
