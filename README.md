# This is my Portfolio Website

# Description
    This is my portfolio website that shows my projects and work from my studies.

    It also includes information about me, my projects, and how to contact me.

# Responsive Design

    The website uses its own CSS files for mobile, tablet and laptop screen sizes.

    For mobile, it uses screen sizes up to 600px. For tablet, it can go from 601px to 1024px, and laptop can go from 1025px and above.

    These screen sizes make the website adjust to different device sizes.

# Gradient

    I used a linear gradient for the background of the website. It uses a 135-degree angle with dark blue colours. 

    I also used a linear gradient for the main heading on the pages.

# Colour Scheme
    I used an analogous colour scheme from Adobe Color. I used dark blue and light blue colours for the background, headings, navigation, and footer.
